# Calendar Planner

A beautifully designed, fully functional calendar and task management application built entirely with vanilla HTML, CSS, and JavaScript -- no frameworks, no dependencies, just a single file.

## Features

### Calendar
- Month-wise navigation with Monday-first grid layout
- Visual task status indicators (hourglass for pending, green tick for complete)
- Circled highlight for today's date

### Weekly Schedule View
- Google Calendar-style weekly timeline (6 AM – 11 PM)
- Tasks positioned at their exact time slots
- Color-coded blocks by category
- Week navigation with quick "Today" jump

### Task Management
- Time-slotted tasks with From/To scheduling
- Priority tags (High, Medium, Low) with color-coded backgrounds
- Category tags (Work, Personal, Health, Study)
- Inline editing, auto-sort by time, and overdue detection
- Progress bar with real-time completion tracking
- Optional notes per task and one-click cleanup
- 5 dedicated daily Must-Do items

### Live Sidebar
- Real-time weather and location via Geolocation + Open-Meteo API
- Live digital clock with seconds
- Daily rotating motivational quotes

### Design
- Clean, light-themed UI with navy and gold accents
- Responsive layout for all screen sizes
- Smooth animations and transitions
- All data persisted in localStorage -- fully offline, no backend

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties, Animations)
- Vanilla JavaScript (ES6+)
- Open-Meteo API (weather)
- Nominatim API (reverse geocoding)

## Getting Started

No installation needed. Just open `index.html` in your browser.
